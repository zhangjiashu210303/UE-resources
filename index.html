assets.json 写法
[
  {
    "name": "T_Rock_01.png",
    "downloadDir": "/Game/Textures/Terrain",
    "url": "https://cdn.example.com/tex/rock01.png"
  },
  {
    "name": "SK_Intro.mp4",
    "downloadDir": "/Game/Movies",
    "url": "https://cdn.example.com/video/intro.mp4"
  }
]

// 名称字段: name / title / filename / 名称 / 文件名
// 目录字段: downloadDir / dir / folder / path / 下载目录 / 保存目录
// 地址字段: url / downloadUrl / src / image / video / 地址 / 下载地址
// 目录可以省略，省略时写入浏览器下载目录
