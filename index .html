GitHub 发布设置

填一次即可，Token 会保存到浏览器本地

首次使用需要填 Token（约 1 分钟）
  1. 打开 github.com/settings/personal-access-tokens/new
  2. Token name 随便填，Expiration 选 90 天
  3. Repository access 选 Only select repositories，勾选 UE-resources
  4. Permissions → Repository permissions → Contents 设为 Read and write
  5. Generate token → 复制 github_pat_... 粘贴到下面
Token 只保存在你浏览器本地（localStorage），只发送给 api.github.com。
